# POS Topup E-Money Wallet UI

**Date:** 2026-07-13  
**Status:** Approved

## Goal

Restyle `/dashboard/pos/topup` as an e-money top-up screen with a large wallet card showing remaining ARK balance.

## Layout

1. Idle: tap NFC / find member CTA
2. Selected member: wallet card (name, tier, card ID, large balance + IDR equivalent)
3. Below: amount presets, custom input, projected balance, payment method, confirm
4. Keep existing NFC resolve + create-member flows
